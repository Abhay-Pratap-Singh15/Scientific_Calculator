# Scientific Calculator with History (Java + Swing + MySQL)

This is a Java Swing-based scientific calculator that supports basic and advanced calculations with a GUI. It also includes a history feature that saves all expressions and results in a MySQL database.

---

## ✨ Features

- Standard calculator functions (+, −, ×, ÷, %, etc.)
- Scientific functions: sin, cos, tan, log, sqrt, ^, etc.
- "DEL" button to delete last character
- "AC" to clear input
- "MO" button to toggle Scientific Mode
- "HS" button to view full history from MySQL database
- Clean and modern Java Swing UI
- Rounded buttons and intuitive layout

---

## 🛠️ Technologies Used

- Java 18+
- Swing (Java GUI)
- MySQL 8.x
- Maven (for dependency management)
- JDBC (for database interaction)
